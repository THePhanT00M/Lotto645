# 엔진 진단 스크립트

추천 엔진을 바꾼 뒤 "정말 나아졌는지"를 수치로 확인하기 위한 도구다.
느낌이 아니라 측정으로 판단하려고 남겨 둔다.

```bash
pnpm engine:backtest      # 과거 회차로 적중률을 무작위와 견준다
pnpm engine:distribution  # 추천·decoy의 번호 쏠림을 카이제곱으로 잰다
pnpm engine:tune          # 학습 횟수별 정확도·Brier·시간을 비교한다
```

Supabase 접속 정보가 필요하므로 `.env`가 있어야 한다.

## 읽는 법

**engine:backtest** — 1~1000회로 학습하고 1001회 이후를 맞혀 본다.
평균 적중 개수의 95% 신뢰구간이 겹치고 z가 ±1.96 안이면 무작위와 차이가 없다는 뜻이다.
로또는 무작위 추첨이라 이 값이 유의하게 나오는 쪽이 오히려 이상하다.
적중률은 개선 대상이 아니라 **회귀 감시용**으로 본다.

**engine:distribution** — 카이제곱이 임계값(자유도 44에서 60.5)을 넘으면 번호가 고르지 않다는 뜻이다.
실제 당첨 번호가 29 안팎이므로, 추천도 그 근처여야 정상이다.
반대편 예시(decoy)가 치우치면 판별 경계가 격자 일부에만 맞춰진다.

**engine:tune** — 학습 횟수를 늘릴수록 정확도가 떨어지고 Brier가 나빠지면 과적합이다.
설정을 바꾸기 전에 이 표를 먼저 확인한다.
